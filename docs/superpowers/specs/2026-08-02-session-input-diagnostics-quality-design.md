# WinARD 会话输入、诊断与连接质量设计

## 目标

修复远程会话中普通字符可以输入、但 Enter 未被转发到 macOS 的问题，并让用户在会话仍正常显示时也能导出脱敏诊断。同时在会话状态栏显示基于实际画面响应时间的连接质量指示灯。

## 范围

- 仅修改 WinARD 桌面会话窗口、输入事件接入、会话视图模型及其测试。
- 不修改 ARD 加密、认证、控制模式、key、IV、sequence 或服务器消息格式。
- 不引入主动网络探测、坐标扫描或额外的全屏刷新。
- 不在诊断中记录按键、密码、剪贴板内容、像素数据或协议密文。

## Enter 输入修复

`RemoteInputSurface` 继续保留现有控件类型、焦点、指针和光标行为。会话窗口不再仅依赖普通的 `KeyDown +=` 和 `KeyUp +=` 订阅，而是通过支持 `handledEventsToo` 的路由事件注册捕获已经被 WinUI `Button` 基类处理的键盘事件。

Enter 按键继续使用现有映射：

```text
KeyDown -> X11 keysym 0xff0d, down=true
KeyUp   -> X11 keysym 0xff0d, down=false
```

事件仍经过 `RemoteInputOperationRunner`、`WindowsInputMapper`、`IRemoteSessionRuntime.SendKeyAsync` 和现有加密传输。普通字符、修饰键和指针路径不变。窗口关闭时移除通过 `AddHandler` 注册的处理程序，避免窗口生命周期结束后继续接收输入。

## 当前会话诊断入口

在远程会话工具栏增加“导出诊断”按钮。该按钮调用现有 `DiagnosticExportService` 和 `DesktopDiagnosticContextFactory`，与错误卡片使用同一脱敏导出链路。

- 服务可用时按钮启用。
- 服务不可用或会话正在关闭时按钮禁用。
- 用户取消保存不显示错误。
- 导出失败通过现有安全错误处理显示，不记录敏感内容。

诊断入口只改善可访问性，不扩大诊断字段范围。

## 连接质量指示灯

### 数据来源

每次发送 `RequestFramebufferUpdateAsync` 时记录单调时钟时间。当下一条 `RemoteFramebufferMessage` 或 `RemoteCursorMessage` 到达时，计算该次请求的响应时间。只使用完整的请求—响应样本，不根据静止时间推断网络质量。

使用最近样本的指数移动平均值降低瞬时抖动：

```text
首次样本：average = sample
后续样本：average = 0.25 * sample + 0.75 * previousAverage
```

### 显示状态

| 状态 | 颜色 | 条件 |
| --- | --- | --- |
| 未采样 | 灰色 | 尚未收到完整响应时间样本 |
| 良好 | 绿色 | 滚动响应时间小于 150 ms |
| 一般 | 黄色 | 滚动响应时间为 150–500 ms |
| 较差 | 红色 | 滚动响应时间大于 500 ms |
| 已断开 | 红色 | 会话结束或发生连接错误 |

状态栏显示彩色圆点和简短文字，例如“良好 · 82 ms”。静止桌面不产生新响应时保持最后一次已测结果，避免把无画面变化误判为网络故障。自动化属性和文本同时表达状态，不能只依赖颜色。

### 边界与失败处理

- 使用单调时钟，系统时间变化不影响结果。
- 每次最多保留一个未完成的画面请求时间戳。
- 收到剪贴板、响铃或 ARD 控制消息不结束画面响应计时。
- 会话停止后清除待处理请求并显示“已断开”。
- 指示灯是画面链路响应估计，不宣称等同于 ICMP/TCP RTT。

## 测试

按照 TDD 顺序增加以下回归测试：

1. 会话窗口必须用 `handledEventsToo` 注册键盘按下和释放事件，修复前测试失败。
2. Enter 产生完整的 `0xff0d` down/up 序列；普通字符映射保持不变。
3. 会话工具栏包含可访问的“导出诊断”按钮，并复用现有导出服务。
4. 质量计算覆盖首次样本、指数移动平均和 149/150/500/501 ms 边界。
5. 静止时保持最后样本；断开后切换为红色“已断开”。
6. 运行桌面定向测试、完整 Release x64 构建和全量解决方案测试。

## 成功标准

- Windows Enter 的按下和释放能够进入现有远程键盘发送链路。
- 用户无需等待错误卡片即可从会话工具栏导出脱敏诊断。
- 质量灯由真实画面请求—响应样本驱动，并明确区分未采样、良好、一般、较差和断开。
- 不改变 ARD 协议或削弱现有敏感数据保护。
