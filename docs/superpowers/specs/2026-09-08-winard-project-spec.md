# WinARD 整项目完成规格

日期：2026-09-08。项目级验收基准；配套[报告](../../testing/2026-09-08-winard-project-handoff-report.md)和[计划](../plans/2026-09-08-winard-project-plan.md)。专项规格保留技术细节，完成结论需满足本规格。

## 1. 产品目标

Windows 10 22H2/Windows 11 x64客户端，使用macOS自带远程管理，通过TCP或Windows OpenSSH连接并控制Mac。Mac零安装，提供可靠的设备管理、秘密存储、画面输入、画质调整、重连和诊断。

当前优先级：保住基础远控正确性 → 证据与测试收敛 → 缩放/MVS和低帧率闭环 → 正式交付。任何性能优化不得牺牲权限边界、秘密安全或像素/输入正确性。

最终完成包含功能、性能证据、稳定性、兼容与发布。文档、探针、单测或包存在均不能单独满足完成定义。

## 2. 功能要求

### 连接与设备

支持保存、搜索、编辑、删除、Bonjour草稿与保存项双击连接；单击只选择。发现不自动保存或认证。单活动会话租约，连接/重连期间不重复占用。

ARD Type30及已实现的003.889控制/加密流程可用；权限拒绝、错误认证、版本不支持和网络失败准确分类。SSH跳板与Mac目标独立，密码/私钥/口令可用，首次主机密钥确认和变化拒绝通过真实测试。

### 画面与输入

标准Zlib/ZRLE/Raw稳定连续解码，D3D呈现和脏区正确，光标与四角/中心坐标匹配；键盘、Unicode、组合键、纯文本剪贴板正确。窗口失焦、弹层、取消、断线和关闭释放远端已按键，不能泄漏本地输入。

全屏热区/快捷键唤回，Esc依本地下拉→画质面板→全屏层级消费；定时任务取消/关闭后不回写旧UI。

### 设置与凭据

Windows凭据、加密Vault、Ask三种模式语义一致。主题、剪贴板默认、日志等级、立即/自动锁定实际生效。秘密不存明文SQLite或日志。

迁移copy/readback/版本核对后事务CAS引用与默认后端；失败保留源与原引用，提交后用户决定源清理。跨进程写锁崩溃可恢复，退役引用不能复活；新秘密生成合法新引用。会话质量/主机密钥更新不回写旧凭据，重连读取最新引用。Ask应真正提示，不静默使用旧持久秘密。

### 重连和回退

暂态错误带有界退避、次数、倒计时和取消；确定性认证/权限/协议/主机密钥错误停止。取消与关闭等待活动attempt退出后释放租约。手动和自动路径串行、最新profile可见。

启动画质兼容失败共享首选加一次安全连接预算，不无限重试；MVS研究不得增加第三条隐式连接。运行期坏流停止并按明确恢复策略处理。

## 3. 分辨率与刷新率

保留自动/100/75/50/25档及原自动带宽映射，显示请求、解析、实际像素尺寸和生效状态。本地Fit/缩放独立命名。未经有效像素尺寸确认不能显示比例已生效。

连接前、在线两类缩放能力分别验证。当前十字节请求未在实测中降尺寸，应继续协议取证；不能直接套用其他VNC type8。仅启动支持则要求重连；在线往返证据通过后才开放动态切换。

刷新率保留用户确认的30、45、60、75、90、105、120与无限及自适应/手动方式；目标与实际FPS分开。Mac最大刷新能力只有取得可信数据时才显示，不臆造上限。用户锁定的比例/色彩/刷新率不被自动策略覆盖。

## 4. MVS 与性能

1011已被真实Mac选择，但格式与解码正确性仍需验证。E2b要求完整语法、独立整图答案、完整载荷消费、真实大矩形和连续状态；E3要求安全decoder及真机输入/画面；E4要求性能稳定性。经验系数或样本匹配不能替代协议。

独立验收图至少有中间色、棋盘、文字、渐变和彩色边缘，不只纯色或首像素；预期不由被测decoder生成。有损误差先定义、后验证。未知模式拒绝，不估色报成功。

保留固定小缓冲，分配前checked预算，长循环取消，失败不发布半帧。MVS产品默认关闭至E3，自动优选至E4。允许灰度，不自动黑白；不分发RDM DLL，不因名称假定H.264/JPEG。

性能以同设备/显示布局/尺寸/负载/链路比较。静态、滚动、拖动或动画各三轮每轮30秒，报告每轮和中位数、实际FPS、字节、请求等待/接收/解码/呈现、CPU/内存与输入延迟。合计耗时不能叫网络RTT；静态低FPS非失败；全帧探针不等于增量应用FPS。

目标是可复核改善和可读性保持，不承诺固定带宽倍数。若缩放或MVS未完成，可交付准确标识的标准编码候选，但不能称整个优化目标完成。

## 5. 诊断、安全与交付

普通诊断仅白名单版本、关联ID、稳定错误、受限指纹与有界聚合数据；拒绝host/user/path/secret/clipboard/raw exception/媒体载荷。研究样本独立受控，采集前用户确认合成场景。

同一候选需全量测试、Release零警告、format、许可证/漏洞和产物校验。未签名MSIX只能工程候选；正式签名、签名后哈希和Windows10/11干净环境安装/运行/卸载另行验收。

macOS12/13/14/15/26与Windows10/11矩阵按真实结果填写，至少声明支持的组合完成TCP、SSH和凭据回归。两小时会话无崩溃、粘键、卡死和持续内存增长。未测组合明确写未验证。

不包括文件传输、音频、打印、云中继、Mac helper和额外多显示器编排。现有复合桌面接收仍需正确，不能因不做编排而忽略大尺寸/坐标。

## 6. 验收矩阵

| 编号 | 领域 | 必需证据 |
|---|---|---|
| A1 | TCP/ARD控制 | 登录、桌面、错误账号、权限拒绝、退出 |
| A2 | SSH | 密码/私钥/口令、首信任/变化拒绝、取消清理 |
| A3 | 设备UI | 草稿、保存/编辑/删除、实际命中双击、单会话 |
| A4 | 呈现输入 | 复杂画面、光标/四角、Unicode、剪贴板、失焦释放 |
| A5 | 设置凭据 | 三模式、锁定、迁移失败/取消/并发/崩溃、重连新引用 |
| A6 | 重连全屏 | 自动/手动竞争、取消/关闭、热区/快捷键/Esc |
| A7 | 缩放 | 请求/实际一致、失败明确、各比例能力范围、坐标 |
| A8 | MVS | 独立图像与连续大切片、畸形流、回退、实际状态 |
| A9 | 性能 | 同负载测量与两小时稳定性 |
| A10 | 发布 | 同版本测试/哈希/许可证/签名/干净安装及仓库交接 |

所有结论区分源码实现、单测通过、真机通过和正式发布。缺一项必须明确剩余范围，不通过重命名阶段来宣称完成。
